# 🏨 Hotel Management System

## 📌 Project Overview
The Hotel Management System is a desktop application developed using **Python**, **PyQt Designer**, and **MySQL**. It helps manage hotel operations such as room booking, customer records, check-in/check-out, food orders, and billing through a user-friendly interface.

---

## 🚀 Features

- 🛏️ Room Management
- 👤 Customer Registration
- ✅ Check-In & Check-Out
- 🍽️ Food Booking
- 🗄️ Customer Record Management
- 🔍 Search Customer Details
- ✏️ Update Customer Information
- ❌ Delete Customer Records
- 💾 MySQL Database Integration

1. Install Python.
